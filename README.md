# Reseller Fee Calculator

This static website is a free U.S. reseller pricing tool for estimating fees, target listing prices, shipping impact, and profit.

## Local development
- Open the HTML files directly in a browser or serve the files with any static server.

## Fee assumptions
- Fee assumptions are stored in `fees.config.js` and are used as planning estimates only.

## Deploy
- Deploy the repository to Vercel without a build step.
